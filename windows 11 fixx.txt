## Importing mhacto_db_export_20260226.sql into MariaDB on Windows 11

### Option 1: Command Prompt (Recommended)

1. Open Command Prompt (cmd.exe) as Administrator
   NOTE: Use CMD, NOT PowerShell. PowerShell does not support the < operator.

2. Navigate to MariaDB bin directory:
   cd "C:\Program Files\MariaDB\MariaDB 11.x\bin"

3. Create the database:
   mysql -u root -p -e "CREATE DATABASE mhacto_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"

4. Import the SQL file (CMD only):
   mysql -u root -p mhacto_db < "C:\path\to\mhacto_db_export_20260226.sql"


### Option 1b: PowerShell Alternative (if you must use PowerShell)

   PowerShell does NOT support < for input redirection. Use this instead:

   Get-Content "C:\path\to\mhacto_db_export_20260226.sql" | mysql -u root -p mhacto_db


### Option 2: MariaDB Shell

   CREATE DATABASE IF NOT EXISTS mhacto_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
   USE mhacto_db;
   SOURCE C:/path/to/mhacto_db_export_20260226.sql;

   NOTE: Use forward slashes (/) in the SOURCE command path.


### Option 3: HeidiSQL (GUI)

1. Open HeidiSQL and connect to MariaDB
2. Right-click database > Import SQL file
3. Select mhacto_db_export_20260226.sql


### Common Issues & Fixes

- '<' not accepted in terminal  -> You are using PowerShell. Switch to CMD (cmd.exe) or use Get-Content file.sql | mysql -u root -p mhacto_db
- 'mysql' not recognized       -> Add MariaDB bin folder to Windows PATH environment variable
- Access denied                -> Use correct credentials: -u root -p
- Sandbox mode warning         -> The /*M!999999\- enable the sandbox mode */ line is harmless, ignore it
- Foreign key errors           -> Already handled by FOREIGN_KEY_CHECKS=0 in the dump
- Character encoding issues    -> Always create DB with utf8mb4 charset
